# App Icons

Place your app icons here for the PWA and Capacitor builds:

- `icon-192.png` (192×192)
- `icon-512.png` (512×512)

You can generate them easily at:
- https://www.pwabuilder.com/imageGenerator
- https://favicon.io
- https://realfavicongenerator.net

Recommended: Use a simple car/speedometer icon on a dark red (#c41e3a) or navy (#1a1a2e) background.
